# 🚀 Proyecto Integrador: Sistema Modular Orientado a Objetos (POO)

Este repositorio contiene la arquitectura, el diseño de clases y el código fuente del prototipo desarrollado para el **Proyecto Integrador del Tercer Semestre**, enfocado en la aplicación estricta de los principios de **Programación Orientada a Objetos (POO)**.

## 📅 Planificación y Distribución de Tareas (POO)

| Actividad / Tarea | Hito Asociado | 
| :--- | :--- | :--- |
| **1. Análisis y Diseño de Clases (UML)** | Hito 1: Estructura de entidades y relaciones | 
| **2. Implementación de Pilares POO (Herencia, Polimorfismo)** | Hito 2: Desarrollo del núcleo lógico | 
| **3. Concurrencia y Estructuras de Datos Seguras** | Hito 3: Gestión de memoria y hilos | 
| **4. Capa de Control y Ejecución (Cliente-Servidor / App)** | Hito 4: Conectividad y flujos | 
| **5. Pruebas Finales y Documentación** | Hito 5: Entrega y validación del parcial |

## 🛠️ Tecnologías y Paradigmas

* **Paradigma:** Programación Orientada a Objetos (POO) - Encapsulamiento, Herencia, Polimorfismo, Abstracción.
* **Lenguaje:** Go / Lenguaje de programación del parcial.
